# 웹 시드머니 주기별 반영 기록 인수인계

요청: 웹 홈의 '시드머니가 쌓인 모양' 그래프. 계약은 [API — 웹사이트 연동](API.md#웹사이트-연동).

## 구현 범위

- 기존 `GET /internal/v1/web-links/{linkId}/seed-money`에 `startedOn`, `entries` 추가. 기존 5개 필드와 오류 응답 유지.
- 확정 기록 전체를 주기 종료일 오름차순으로 전달. GOAL / ALL / MANUAL과 명시적으로 반영한 0원 포함, 미반영 주기·pending·후보 금액·거래 제외.
- `totalAfter`는 조회 시점의 base 기준 누적값. base 수정 시 과거 점도 같은 기준으로 다시 계산하며 저장된 반영 금액은 그대로다. 마지막 누적값은 total과 같다.
- `startedOn`은 첫 하루 예산 기록일(`daily_budgets.budget_date`의 최솟값). 첫 조회 전에는 null. 웹이 null을 처리해야 한다.
- DB 마이그레이션·앱 JS 업데이트는 필요 없다. 백엔드 배포는 사람이 한다.
- 배포 순서(2026-10-21 사용자 결정): 웹이 추가 필드와 이미 호환되므로 이 백엔드 API는 먼저 배포할 수 있다. 앱의 웹 연동 설정 화면은 개인정보처리방침을 확정한 뒤 별도 원격 업데이트로 반영한다.
- 제공 범위는 [앱·웹 서비스 경계 §5-2](https://github.com/shinds-team7/flexable-web/blob/main/docs/product/04-service-boundaries.md)가 기준이다. 앱 HANDOFF에 있었던 ‘이후 유동자산 집계’는 정본 범위 밖이며, 넘기려면 정본을 먼저 고치고 계약·개인정보 제공 항목을 합의해야 한다. 이번 변경에는 포함하지 않는다.
