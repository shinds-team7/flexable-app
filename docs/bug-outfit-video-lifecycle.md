# 꾸미기 이동·선택 후 영상 오류 (2026-10-21)

사용자 Android 오류 화면: `VideoPlayer.pause`가 거절되며 `Cannot use shared object that was already released`가 표시됨. 처음에는 재생됐지만 꾸미기 진입·복귀 후 정지하거나 오류 화면이 나옴. 기본 코스튬에서도 보고됨.

`OutfitView`는 기본·상점 코스튬이 함께 사용한다. 기존 `useVideoPlayer`는 컴포넌트가 없어질 때 네이티브 플레이어를 자동 해제하고, 뒤이어 등록된 `useFocusEffect`의 정리 함수가 같은 플레이어에 `pause()`를 호출했다. 코스튬 선택은 `key`를 바꿔 컴포넌트를 교체하므로 같은 정리 경로를 거친다. 오류 메시지와 설치된 Expo SDK 57 코드에서 확인한 충돌 경로이며, 연결된 Android 기기는 없어 기기에서 호출 순서를 직접 추적하지는 못했다.

수정: `useIsFocused`로 현재 화면에만 영상 컴포넌트를 마운트한다. 화면 이탈·선택 변경 때 자동 해제만 수행하고 별도 정리 함수에서 플레이어를 호출하지 않는다. 복귀 때 새 플레이어를 만들고 생성 설정에서 재생을 시작한다. 목록·구매 모달·동작 줄이기 설정에서는 정지 그림을 유지한다. 네이티브 패키지·버전 변경은 없다.

검증 범위:

- 네이티브처럼 해제 후 호출을 거부하는 모의 플레이어로 실제 `OutfitView.tsx`를 실행하는 회귀 테스트. 선택 변경·화면 이탈·복귀·정지 그림 경로를 검증한다. Android 실행을 대신하지 않는다.
- 웹 E2E: 구매·적용 전 기본 코스튬으로 홈↔꾸미기 3회, 미리보기 반복 선택, 각 화면에서 영상 하나만 존재하고 재생되는지 검사한다. 기존 구매·적용 흐름도 유지한다.
- 실기기 확인 필요: 업데이트를 받은 1.4.0 Android에서 기본 코스튬의 홈↔꾸미기 왕복·뒤로가기·반복 선택·적용 후 홈 영상 재생. 처음부터 정지한 경우 동작 줄이기 설정과 별도 영상 로드 오류도 확인한다.
