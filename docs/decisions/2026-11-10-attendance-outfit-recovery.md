# 기존 7일 출석자의 보상 복구와 잠금 이미지 복원

- 날짜: 2026-11-10 · 결정한 사람: 사용자 · 관련: 배포 후 출석 보상 미해금 보고
- 영향: 앱 화면 / 앱 서버

## 결정

- 누적 출석 7일 이상인데 `outfit-06` 소유 기록이 없는 회원은 V28에서 보상을 복구한다. 0코인 출석도 하루로 센다. 이전 `outfit-07` 보상·구매와 기존 코인은 그대로 둔다.
- 이미 `outfit-06`이 있으면 중복 지급하거나 획득 시각을 바꾸지 않는다. 7일 미만인 회원은 잠금을 유지한다.
- 11-09 결정의 ‘변경 전 보상 추가 지급 없음’ 중 이 누락 복구는 사용자 요청에 따른 예외다. 이후 신규 출석의 7일 보상표는 그대로다.
- 조선 세 번째 출석 보상, 도전과제, 업데이트 예정 칸은 해금 전 기존 눈코입 없는 흰색 `cat-unlock.png` 위에 짙은 회색 레이어와 흰색 자물쇠를 표시한다. 눌러서 실제 영상을 미리 볼 수 없다.
- `outfit-06` 해금 후에는 굴비 고양이 썸네일·영상을 표시하고 적용할 수 있다. 흰색 이미지는 잠금 전용으로 별도 유지한다.

## 확인

V27→V28 업그레이드에서 6일·7일·8일 출석, 옛 보상 보유·기보유자 보존을 검사한다. 브라우저에서 잠금 그림·가림·해금 후 적용 버튼을 확인한다. 운영 사용자별 실제 데이터는 직접 조회하지 않는다.
