# 광고 보상: 시청 시간별 10·15·20코인

- 날짜: 2026-11-07(11-06 합의, 방식은 11-07 채팅에서 승인) · 결정한 사람: SXXNHU · 상태: **승인, 구현**(Issue #278)
- 영향: 앱 서버(`POST /coins/ad-bonus`, 내역 사유 `AD_BONUS`, 오류 `AD_NOT_REWARDED`), 앱 화면(상점 [광고 🪙], 자동 적립 안내 모달), API 계약
- 바뀌는 기준 문서: `contracts/app-api.yaml`, `coin-plan.md` "광고 보상", `API.md`, `FEATURES.md`

## 배경

기본 보상은 AdMob 서버 검증(SSV) 콜백이 지급한다. 콜백에는 광고 길이·시청 시간이 없고, 앱이 광고 요청 때 실을 수 있는 값(`custom_data`)은 광고를 보기 전에 정해지므로 앱이 잰 시청 시간을 콜백에 담을 수 없다.

## 결정

1. **기본 10은 지금처럼 SSV 콜백**이 준다(하루 3번, `transaction_id`당 한 번).
2. **보너스는 앱이 광고를 닫은 뒤 `POST /coins/ad-bonus {requestId, watchedSeconds}`**로 받는다. 시간은 광고가 열린(`OPENED`) 때부터 닫힌(`CLOSED`) 때까지 앱이 잰다. 15초 미만 0, 15~30초 +5, 30초 이상 +10.
3. **앱이 잰 시간을 믿는다.** 코인은 앱 안에서만 쓰고 현금·결제 가치가 없어 위조 대응(광고 길이 확인 등)은 하지 않는다. 대신 보너스는 그날 받은 광고 보상 수까지만(광고 1번에 1번) 주고, 같은 `requestId`는 한 번만 지급한다. 보너스 0은 기록하지 않는다.
4. **콜백이 늦을 때**: 보너스 요청이 콜백보다 먼저 오면 409 `AD_NOT_REWARDED`. 앱은 1.5초 간격으로 8번까지 다시 보낸다(예전 지갑 다시 읽기와 같은 시간).
5. **화면**: 상점 버튼은 "광고 🪙". 다 보면 자동 적립 뒤 "+15 코인을 받았어요" 안내 모달.
6. 내역 사유 `AD_BONUS`를 새로 더했다. 옛 앱(1.8.0 번들)은 모르는 사유를 "코인"으로 보여 주므로 깨지지 않는다.

## 확인이 남은 것(사람)

- 서버 배포 후 원격 업데이트(순서: **서버 먼저**. 옛 서버에 새 앱이 보너스를 요청하면 404라 지갑으로 기본 10만 확인해 "+10" 안내로 끝난다).
- 실기기: 실제 광고 길이별(5·15·30초 광고) 보너스, 콜백 지연 때 안내 모달.
