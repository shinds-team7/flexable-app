# 내 기록 기준 요일 비중의 월요일 갱신

- 날짜: 2026-11-10 · 결정한 사람: 사용자 · 관련: Issue #335
- 영향: 앱 화면 / 앱 서버

## 결정

- `RECORD` 프리셋을 새로 선택하면 전날까지의 직접 기록 지출로 비중을 정하고, 선택한 주에는 그 값을 유지한다.
- 이후 매주 월요일 한국 시간에 직전 일요일까지의 최대 3개월 기록으로 비중을 다시 계산한다. 이번 주 기록은 다음 월요일에 반영한다.
- 기록이 부족해 새 비중을 낼 수 없으면 마지막으로 저장된 비중을 사용한다. `CUSTOM`을 비롯한 다른 프리셋은 자동 갱신하지 않는다.
- 서버가 `GET /budget/today`와 `GET /budget/day-weights`의 적용 비중을 같은 규칙으로 정한다. 프리셋 후보와 기록 기간은 기존 API 계약대로 호출 시점의 전날까지 계산한다.

## 구현·호환성

`budget_settings.day_weights_chosen_at`을 V27에서 추가하고 기존 RECORD 사용자에는 마이그레이션 시각을 넣는다. 배포한 주에는 기존 저장 비중을 유지하고 다음 월요일부터 갱신한다. 응답 형식은 바꾸지 않는다. 앱은 서버 금액을 그대로 표시한다.
