# iPhone 첫 버전 (#394)

동일한 Expo 프로젝트와 Spring 서버를 쓴다. 기존 예산·거래·계정 삭제 계약으로 iPhone에서도 같은 데이터를 읽고 쓸 수 있다. 이번 제출은 iPhone용이다.

- 이메일 가입·로그인만 제공한다. Apple 심사 지침 4.8은 자체 계정 시스템만 쓰는 앱을 예외로 둔다. 기존 카카오·Google 연결 계정은 서버가 이메일 로그인을 거절하므로 iPhone에서 해당 계정으로 들어갈 수 없다. 기존 이용자에게 Android·웹 로그인 경로를 안내한다. 소셜 로그인을 iOS에 추가할 때에는 동등한 개인정보 보호 옵션과 계정 연결·탈퇴 계약을 함께 설계한다. [Apple 4.8](https://developer.apple.com/app-store/review/guidelines/#login-services)
- 결제 알림 접근·상시 예산 알림·스크린샷 OCR은 Android 구현에 의존한다. iPhone에서는 직접 기록과 거래내역서 PDF 등록을 제공한다. 수입일·기록 알림은 기기 자체에서 예약한다.
- 광고 보상은 Android에만 제공한다. 기존 AdMob 앱 ID와 광고 단위는 Android용이다. iOS에는 광고 SDK를 링크하지 않으며 출석·시간 적립·추천 코인과 코스튬은 계속 이용할 수 있다.
- iOS AI 메이트는 대화에 들어가기 전 Google Gemini에 보내는 정보와 목적을 설명하고 동의를 받는다. 대화 화면을 새로 열면 다시 묻는다. 음성 인식·합성은 첫 버전에서 제외한다. [Apple 5.1.2(i)](https://developer.apple.com/app-store/review/guidelines/#data-use-and-sharing)
- iOS 원격 업데이트는 네이티브 의존성 지문이 일치하는 빌드에만 적용한다. 스토어 메타데이터와 개인정보 답변은 해당 플랫폼에서 실제 제공하는 기능을 기준으로 작성한다.
