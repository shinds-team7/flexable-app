# 음성 일정 개편: 한 줄 예정 지출 카드·AI 음성 답변·+ 음성 입력

- 날짜: 2026-11-07(11-06 합의 정리) · 결정한 사람: SXXNHU · 상태: **승인, 구현**(Issue #277)
- 영향: 앱 화면(AI 메이트 대화·+ 시트), 앱 서버(일정 금액 예측 #279), 개인정보처리방침 추가 개정(3)
- 바뀌는 기준 문서: `policies.md` §8(#279), `play-store/privacy-policy.md`, `FEATURES.md`

## 결정

1. **듣는 중 표시**: 안내 줄("듣고 있어요")을 없애고 마이크 버튼만 빨간 멈춤으로 바꾼다. 대화 화면에서는 듣는 동안 사용자 쪽에 "…" 말풍선을 띄운다(메뉴 화면은 대화가 없어 버튼만). 들은 문장은 지금처럼 입력창에만 넣고 [보내기]는 사용자가 누른다.
2. **예정 지출 한 줄 카드**(`service/ScheduleCard.tsx`, 규칙은 `service/scheduleDraft.ts`): 날짜 · 금액 · 카테고리와 [반영 | 수정]. 날짜 → 앱 캘린더(내일~90일 뒤), 금액 → 숫자 입력, 카테고리 → 지출 카테고리 모달(거래 입력과 같은 아이콘 칸). 처음엔 [반영]만 켜지고, 하나라도 고치면 [반영]이 꺼지고 [수정]이 켜진다. 금액을 예측하지 못하면 칸이 비고 금액을 넣어야 [수정]이 켜진다. 예전 [등록]·[금액·날짜 바꾸기]·[취소] 버튼은 없앤다(말로 고쳐 달라고 하는 흐름은 그대로).
3. **AI 음성 답변**: 기기·브라우저 내장 음성 합성(`expo-speech`)만 쓰고 서버로 보내지 않는다. 읽는 것은 예정 지출 확인 질문 한 줄("11월 7일에 데이트로 56,200원을 등록할까요?")뿐이다. AI 메이트에 처음 들어오면(스타일 선택 뒤) 쓸지 묻고, 대화 화면 헤더의 스피커 버튼으로 바꾼다. 선택은 기기 저장소(`chatbot.voiceReply`)에만 둔다. 마이크를 켜거나 [반영]·[수정]을 누르면 읽기를 멈춘다.
4. **+ 음성 입력**: + 시트 맨 위 [음성 입력](음성 인식을 쓸 수 있을 때만). 누르면 바로 듣고, 말이 끝나면 들은 문장 하나를 AI 메이트와 같은 `POST /chat/messages`(`accepts: [SCHEDULE]`, 저장한 메이트 말투)로 보내 제안을 받는다. 새 API는 만들지 않는다. 제안이 없으면 다시 말하라고 안내한다. 실제 거래가 아니라 예정 지출로만 등록한다.
5. **서버**: 일정에서 시간대를 뽑지 않고, 금액은 카테고리 하루 합계 중앙값(#279).
6. **개인정보처리방침 추가 개정(3)**: 처음에는 11-07 프로덕션 출시에 맞춰 방침 14장대로 시행 7일 전 공고(11-14 시행)로 적었으나, 같은 날 원격 업데이트를 내면서 **11-07 공고·시행**으로 바꿨다(11-07 사용자 결정). 바뀐 내용은 이 기능이 들어간 앱 업데이트를 받은 이용자부터 적용한다. + 음성 입력은 들은 글자를 [보내기] 없이 바로 AI 메이트로 보내므로 방침에 따로 적었다.
