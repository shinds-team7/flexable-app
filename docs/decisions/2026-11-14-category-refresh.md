# 기본 카테고리 개편과 이름으로 카테고리 추정

- 날짜: 2026-11-14 · 결정한 사람: 사용자(SXXNHU) · 관련: PR #(번호 기입)
- 영향: 앱 화면 / 앱 서버

## 결정

1. 기본 지출 카테고리를 12개(식비·카페·생활·교통·주거·통신·쇼핑·여가·건강·교육·구독·기타)로 바꾼다. 세부 항목(편의점·술집·병원 등)은 카테고리로 두지 않고 추정 키워드로만 쓴다. 더 필요한 카테고리는 사용자가 추가한다.
2. 기본 수입 카테고리는 6개(급여·용돈·금융수입·환급·지원금·기타 수입). 사용자가 제안한 표에서 "부수입"은 뺐다.
3. 술집·술약속은 여가로 분류한다(AI 메이트 일정·지출 제안에도 지시).
4. 기존 사용자도 같은 목록으로 맞춘다(V30): 옛 이름을 새 이름으로 바꾸고 없는 카테고리를 더한다. 사용자가 만든 카테고리·지운 카테고리·거래는 건드리지 않는다.
5. "고정지출" 카테고리는 새 가입자에게 만들지 않는다. 자동 기록은 "고정지출"이 있으면(기존 사용자) 거기, 없으면 "기타". 기존 사용자의 "고정지출"은 거래가 있으므로 지우지 않는다.
6. 이름 추정 규칙은 앱·서버가 같은 키워드 표(`tests/policy/category-guess.json`)를 쓰고, 카드 결제 알림 자동 기록에도 적용한다(이전에는 늘 기타).

## 이유

- 카드 자동 기록이 모든 거래를 기타에 넣었고, 스크린샷·거래내역서 규칙도 키워드가 적어 편의점·병원·오락실 같은 흔한 가맹점을 못 맞췄다(사용자 보고: GS25 연남한양점, 아트박스, 짱오락실, 치과의원).
- 16개 세부 분류를 모두 카테고리로 만들면 고르기가 불편하다(사용자 의견). 대분류 12개 + 키워드로 정확도와 단순함을 함께 얻는다.
- 짧은 영문 상호(CU·KT)는 다른 영문 단어에 섞여 잘못 맞기 쉬워 앞뒤 영문 글자를 막고, 겹치는 이름(스터디카페·쿠팡이츠)은 가장 긴 키워드로 고른다.
