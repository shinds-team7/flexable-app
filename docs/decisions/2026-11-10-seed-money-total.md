# 시드머니는 모은 총액과 이번 달 목표로 표시한다

- 날짜: 2026-11-10 · 결정한 사람: 사용자 · 관련: 이번 채팅의 시드머니 수정 요청
- 영향: 앱 화면 / 앱 서버 / 웹

## 결정

- 카드에는 `total`을 "지금까지 모은 돈", `monthlyGoal`을 "이번 달 모을 돈"으로 표시한다. 후자는 설정한 월 저축 목표이며 확정 저축액이나 자동 이체가 아니다.
- [시드머니 수정]은 처음 입력한 `base`만 바꾸는 대신 현재 총액을 0원 이상 1조 미만으로 정정한다. 과거 저축 기록은 보존한다.
- `PUT /budget/seed-money/total {total}`은 차액을 `ADJUSTMENT` 기록으로 남긴다. 이 기록은 시드머니 합계에만 포함하며 생활비 잔액·하루 예산에서 차감하지 않는다. 같은 총액의 재요청은 기록을 추가하지 않는다.
- 기존 `/base`와 웹의 총액 수정 API 동작은 유지한다. `base`는 처음 입력한 금액이고 `saved`에는 정정 차액도 합산된다. 음수인 `saved`는 내부 구성값이며 카드에 노출하지 않는다.
- 웹 연동의 `entries`·`lastEntry`에도 `ADJUSTMENT`가 올 수 있다. 정정 차액은 음수일 수 있고 마지막 `totalAfter`는 `total`과 같다. 웹에 새 종류 지원을 먼저 알리고 서버·앱 순서로 반영한다.
- 예산 설정·가입 설정의 모아둔 돈 옆에는 `(시드머니 ?)`를 두며 카드와 같은 설명 창을 연다.

## 검증 기준

총액 증액·감액·0원·재저장·동시 수정·회원 분리, 정정 전후 생활비 불변, 이후 실제 보내기의 정상 차감, 웹 누적 합계 일치를 확인한다. API 계약 PR을 구현보다 먼저 병합한다.
