# AI 수입 제안과 수입 설정 부분 변경

- Issue #325: 텍스트와 기기 음성 입력 모두 수입 거래 등록·수정 및 월 수입액·수입일 변경을 지원한다.
- INCOME capability를 알린 앱에만 새 제안을 반환한다. 저장은 사용자의 반영 버튼 뒤 기존 거래 API 또는 새 수입 설정 PATCH로 한다.
- 모델은 사용자가 말한 제목·날짜·금액·카테고리와 수정 대상 조건만 추출한다. 서버가 본인 수입 기록에서 대상을 찾으며, 여러 건이면 되묻는다. 개별 거래·메모나 현재 월 수입 설정을 모델에 보내지 않는다.
- 거래 수정은 요청한 필드만 PATCH한다. 수입 설정은 별도 PATCH로 잔액·기준 시각·고정지출 ID·보호금·시드머니·요일 비중을 보존한다. 기존 수입 설정이 바뀌었으면 409로 재확인을 요구한다. 동일 값 재시도는 성공한다.
- 아직 초기 예산이 없으면 수입 설정 화면으로 안내한다. 미래 수입 거래는 제안하지 않는다. 등록은 수입 금액·제목·날짜가 명확할 때만 한다.
- 배포 순서: 서버 배포 후 앱 원격 업데이트. 서버 기능 전에는 앱이 수입을 저장하지 않는다.
