# UI/UX 요청 전체 반영: 예정 지출·카테고리·AI 메이트

- 날짜: 2026-10-30 · 결정: 사용자 채팅의 보류 없이 전체 진행 지시 · 관련: Issue #212, 기존 #199·#195
- 영향: 앱 화면·앱 서버. 웹 연동 계약은 변경 없음

## 결정

예정 지출은 실제 거래와 분리한 CRUD로 제공하고 기존 예산 계산은 변경하지 않는다. 카테고리는 기본 항목도 삭제하며 기존 거래/예정 기록을 같은 종류로 이동해 보존한다. 지출·수입별 순서를 서버에 저장한다. 홈 평일 내역은 월요일부터 오늘/금요일까지로 표시한다.

AI는 기존 Gemini 서버/화면 작업(#200·#202)을 통합한다. 키는 비워 두고 팀원이 후속 설정한다. 더미 답변을 실제 분석처럼 노출하지 않는다. Gemini 외부 호출과 키 활성화 전 개인정보처리방침 개정 조건은 기존 AI 메이트 결정에 따른다.

## 반영 순서

API 계약·정책 PR을 먼저 올리고, 구현 PR에서 계약/정책 테스트를 추가한다. 새 DB 마이그레이션은 V13(카테고리 순서), V14(예정 지출). 서버 배포 후 앱을 반영한다. Android NavigationBar는 새 네이티브 빌드가 필요하므로 기존 1.5.0 원격 업데이트에는 포함하지 않는다.

## 후속 사용자 지시(2026-10-30)

VM에 Gemini 키가 이미 있음을 사용자가 확인했다. 새 키를 입력·복사·출력하지 않고 서버의 기존 GEMINI_API_KEY를 사용한다. 로컬·CI는 가짜 모델/빈 키로 검증한다. EAS 무료 빌드 소진으로 새 빌드·배포는 11월 1일로 미뤘다. 지금은 기존 runtime 1.5.0/API와 호환되는 UI만 원격 게시하며, NavigationBar 및 새 서버 API 의존 기능은 전체 코드 병합 후 서버 배포·새 빌드/호환 앱 게시 때 반영한다. 현재 PC의 academy SSH 별칭이 없어 VM 검증은 하지 못했다. 운영 AI 활성화 전 개인정보처리방침 관련 기존 결정은 후속 확인한다.
