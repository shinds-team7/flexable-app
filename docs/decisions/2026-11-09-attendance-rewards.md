2026-11-09 기능 추가 요청 반영. 이전 기준(3일차 55, 첫 7일차 낚시 고양이+5, 이후 3·7일차 55)을 대체한다.

- 누적 첫 7회: 5·5·10·5·5·5·코스튬. 첫 7일차는 코인을 지급하지 않는다.
- 이후 7회 주기: 5·5·10·5·5·5·30. KST 하루 한 번이며 결석해도 초기화하지 않는다.
- 출석 보상은 기존 비판매 자리 `outfit-06`을 사용한다. 새 이미지가 오기 전에는 기존 흰색 고양이(`assets/chatbot/mate.png`) 정지 그림을 사용한다. `outfit-07` 낚시 고양이는 코인 상품으로 유지한다.
- 상점 도전과제 목록은 출석 보상과 향후 추가할 빈칸, 총 두 자리다. 미보유 보상과 미래 자리는 그림 없는 자물쇠, 하단은 "도전 과제 달성 시 해금". 미래 자리의 조건·지급은 아직 구현하지 않는다.
- 레벨 코스튬 목록 하단 문구는 보유·적용 여부와 관계없이 "레벨 달성 시 해금"이다. 미리보기의 적용 버튼과 구체적인 잠금 조건은 유지한다.
- 이미 지급한 코인·코스튬은 회수·교환·추가 지급하지 않는다. 기존 누적 일수 다음 출석부터 새 보상표를 적용한다.
- 0코인 출석도 기존 원장에 기록해 누적 일수·중복 방지를 유지한다. API 응답 구조·DB 마이그레이션 변경은 없다. 서버와 앱이 같은 보상표를 쓰도록 앱 원격 업데이트 수신 확인 뒤 서버를 배포한다.
