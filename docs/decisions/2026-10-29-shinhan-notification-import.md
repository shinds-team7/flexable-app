# 신한카드 결제 알림 자동 기록

- 날짜: 2026-10-29 · 요청: SXXNHU · 관련: Issue #205
- 영향: 앱 화면·Android 네이티브·개인정보처리방침. 앱 서버·웹 연동 계약은 그대로다.
- 상태: 이 PR에서 검토할 새 기능. 병합·실기기 확인·새 빌드 배포 전에는 운영 기능이 아니다.

## 결정

1. Android 알림 접근을 사용자가 직접 허용하고 별도 선택 동의 후 기능을 켜야 시작한다. 기본 꺼짐. 신한 SOL페이 `com.shcard.smartpay`의 결제 관련 알림만 처리하며 다른 앱·문자는 읽거나 저장하지 않는다. 권한을 켠 것만으로 수집을 시작하지 않는다.
2. 앱이 실행되지 않는 동안에도 Android 리스너가 알림을 모은다. 앱을 열었거나 활성 상태일 때 로그인한 계정으로 자동 반영한다. 백그라운드 서버 전송·인증 토큰의 네이티브 복제는 하지 않는다. 강제 종료·제조사 절전·OS의 민감 알림 가림으로 수집이 제한될 수 있으며 수집되지 않은 과거 내역을 은행에서 조회하지 않는다.
3. 국내 원화 승인 중 금액·날짜/시각·가맹점이 하나로 읽히는 경우만 `EXPENSE`로 기존 `POST /transactions`를 호출한다. 기본 지출 '기타' 카테고리가 없으면 임의 카테고리를 고르지 않는다. 서버의 예산 계산·잔액 기준 시각 규칙은 그대로다. 입력한 카드 미결제액에 이미 포함한 과거 결제를 다시 가져오면 중복 차감될 수 있어 켠 뒤 도착한 새 알림만 수집한다.
4. 취소·부분 취소·해외 이용·거절·여러 금액·알 수 없는 형식은 자동 기록/삭제하지 않고 확인 대상으로 남긴다. 국내 승인 파서는 가상 예제로 검증하며 실제 신한카드 알림 표본·실기기 검증 전에는 Draft를 유지한다.
5. 같은 알림 재전달은 기기 해시로 중복 수집을 막는다. 전송 전 본문·카테고리를 암호화해 고정하고 항상 같은 `Idempotency-Key`로 재시도한다. 응답 유실 후에는 기존 거래 중복 검사보다 저장한 본문 재시도가 우선이다. 아직 전송하지 않은 알림과 같은 시각(1분 이내)·가맹점·금액인 거래가 있으면 확인 대상으로 남긴다. 실제로 같은 금액을 연속 결제한 경우에도 자동으로 하나를 지우지 않는다.
6. 기기 원문 대기열은 Android Keystore AES-GCM으로 암호화하고 백업 제외 위치에 둔다. 최대 200개. 7일 지난 항목은 다음 앱 실행·알림 처리에서 삭제하고 개수·기간 제한으로 빠진 수를 표시한다. 성공·사용자의 제외 확인 후 원문을 삭제한다. 중복 방지 해시도 7일 범위만 유지한다.
7. 계정이 바뀌거나 로그아웃·탈퇴하면 수집 설정과 대기열을 지운다. 기능을 끄면 원문 대기열을 지우고 수집을 중단한다. 이미 기록한 서버 거래는 직접 삭제·회원 탈퇴 전까지 남는다. 알림 원문·고객 이름·카드번호는 서버로 보내지 않는다.
8. 새 네이티브 모듈이므로 앱/runtime 1.6.0 새 빌드가 필요하다. 기존 1.5.0에 원격 업데이트로 게시하지 않는다. 새 빌드 설치 전 minVersion을 올리지 않는다. 개인정보처리방침 공개 페이지·앱 내 동의 설명·Play 데이터 보안 항목을 먼저 맞추고 배포한다.

## 이유와 기준

사용자가 신한카드 결제 알림 자동 기록 기능 추가와 PR 작성을 요청했다. 즉시 백그라운드 서버 전송보다 기존 로그인 세션·거래 API를 유지하는 구현을 우선한다. 실제 알림 형식을 추측해 금액이나 취소를 반영하지 않는다.

- [Android NotificationListenerService](https://developer.android.com/reference/android/service/notification/NotificationListenerService)
- [Expo 로컬 네이티브 모듈](https://docs.expo.dev/modules/get-started/)
- [신한 SOL페이 공식 배포 패키지](https://play.google.com/store/apps/details?id=com.shcard.smartpay)
- 별도 선택 동의 화면에는 처리 목적·항목·보유 기간·거부 및 철회 방법을 설명한다([개인정보 보호법 제15조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398563)). 법률 검토 완료나 Play 승인으로 취급하지 않는다.

## 바뀌는 것

`frontend/modules/payment-notifications` 로컬 Expo 모듈, 마이의 설정·동의 화면, 서비스 레이아웃 자동 반영, 세션 정리, PRD·FEATURES·개인정보처리방침 양쪽 원문·CHANGELOG·HANDOFF. API 계약과 서버 계산 정책은 변경하지 않는다.
