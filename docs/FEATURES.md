# 현재 기능 기준표

기준 2026-10-24, `main` `83c7981`(앱 1.4.0). 화면만 있는 것과 서버·DB까지 연결된 것을 구분한다. 코드에 있는 것과 운영에 배포된 것은 다를 수 있다. 배포·실기기 확인 기록은 [`HANDOFF.md`](HANDOFF.md)가 기준이다.
기능을 추가하거나 바꾸면 이 표를 같이 고친다. README와 HANDOFF는 이 표를 기준으로 쓴다.
