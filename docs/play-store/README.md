## 1. 비공개 테스트 진행 순서

2023-11-13 이후 만든 **개인 개발자 계정**은 프로덕션 출시 신청 전에 "테스터 12명 이상이 14일 연속 옵트인한 비공개 테스트"를 마쳐야 한다. 조직 계정이면 이 조건이 없다.

1. Play Console → 앱 만들기(위 기본 정보)
2. **앱 콘텐츠**(§3) 전부 완료 — 하나라도 비어 있으면 테스트 트랙 출시가 막힌다
3. **스토어 등록정보**(§2) 완료
4. 테스트 → 비공개 테스트 → 트랙 만들기 → 테스터: 이메일 목록 12명 이상(Gmail 또는 Google 계정 이메일). 여유 있게 14~15명 권장(중간 이탈 대비)
5. EAS로 만든 AAB 업로드(Play 앱 서명 사용) → 출시 노트 → 검토 제출
6. 승인 후 **옵트인 링크**를 테스터에게 보내기(§5 안내문) → 각자 링크에서 "테스터 되기" → Play 스토어에서 설치
7. 14일 동안 12명 이상 옵트인 유지 → 대시보드에서 "프로덕션 액세스 신청"(테스트 내용 설문 작성)

첫 검토는 보통 몇 시간~수일 걸린다. 옵트인 14일은 **테스터가 옵트인한 날부터** 센다.

## 2. 스토어 등록정보

### 간단한 설명 (80자 이하)

```
월세·카드값·비상금 빼고, 다음 월급날까지 오늘 쓸 수 있는 돈을 알려주는 가계부
```

### 자세한 설명 (4000자 이하)

```
"그래서 오늘 얼마 써도 돼?"
텅장관리는 통장 잔액에서 이번 달 나갈 돈을 먼저 빼고, 다음 월급날까지 하루에 쓸 수 있는 돈을 계산해 주는 가계부예요.

■ 오늘 쓸 수 있는 돈
지금 잔액, 월급날, 월세·통신비 같은 고정지출, 아직 안 나간 카드값, 지켜두고 싶은 비상금을 입력하면
다음 월급날까지 남은 날로 나눠 오늘 쓸 수 있는 금액을 보여줘요. 기록할 때마다 바로 다시 계산돼요.

■ 수입·지출 직접 기록
금액, 카테고리, 내용만 입력하면 끝. 식비·카페·교통 같은 기본 카테고리에 내 카테고리를 추가해 쓸 수 있어요.

■ 거래 내역
월별로 기록한 수입·지출을 모아 보고, 수정하거나 지울 수 있어요.

■ 소비 분석
이번 주, 이번 월급 주기 동안 어디에 얼마를 썼는지 카테고리별로 보여줘요.

■ 이런 분께 추천해요
· 월급날 전에 통장이 텅 비는 사회초년생
· 복잡한 가계부 대신 "오늘 예산" 하나만 알고 싶은 분
· 고정지출과 카드값을 빼고 남은 돈을 한눈에 보고 싶은 분

■ 안내
· 은행·카드사 계좌를 연결하지 않아요. 직접 입력한 잔액과 기록을 기준으로 계산한 추정값이라 실제 잔액과 다를 수 있어요.
· 계정과 모든 기록은 앱 [마이 → 계정 삭제]에서 언제든 바로 지울 수 있어요.

문의: ucmnuniverse@gmail.com
```

앱이 제공하는 금융 기능을 묻는다. 텅장관리는 **사용자가 직접 입력하는 예산·가계부 도구**이며 대출, 결제·송금, 투자, 암호화폐, 보험, 계좌 개설·연결 기능이 **없다**. Console 목록에서 예산 관리/개인 재무 관리에 해당하는 항목을 고르고 나머지는 선택하지 않는다. 해당 항목이 없으면 "위 항목 중 해당 없음"을 고른다. TODO: 제출 시 실제 선택지 확인.
