## 1. 비공개 테스트 진행 순서

2023-11-13 이후 만든 **개인 개발자 계정**은 프로덕션 출시 신청 전에 "테스터 12명 이상이 14일 연속 옵트인한 비공개 테스트"를 마쳐야 한다. 조직 계정이면 이 조건이 없다.

1. Play Console → 앱 만들기(위 기본 정보)
2. **앱 콘텐츠**(§3) 전부 완료 — 하나라도 비어 있으면 테스트 트랙 출시가 막힌다
3. **스토어 등록정보**(§2) 완료
4. 테스트 → 비공개 테스트 → 트랙 만들기 → 테스터: 이메일 목록 12명 이상(Gmail 또는 Google 계정 이메일). 여유 있게 14~15명 권장(중간 이탈 대비)
5. EAS로 만든 AAB 업로드(Play 앱 서명 사용) → 출시 노트 → 검토 제출
6. 승인 후 **옵트인 링크**를 테스터에게 보내기(§5 안내문) → 각자 링크에서 "테스터 되기" → Play 스토어에서 설치
7. 14일 동안 12명 이상 옵트인 유지 → 대시보드에서 "프로덕션 액세스 신청"(테스트 내용 설문 작성)

첫 검토는 보통 몇 시간~수일 걸린다. 옵트인 14일은 **테스터가 옵트인한 날부터** 센다.
