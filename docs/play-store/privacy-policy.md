# 텅장관리 개인정보처리방침

`/privacy` 페이지 원문. 운영자명·문의 이메일은 `src/service/config.ts` 값으로 표시한다.

---

ucmnuniverse(이하 "운영자")는 텅장관리(이하 "서비스") 이용자의 개인정보를 「개인정보 보호법」에 따라 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

**개정 안내:** 같은 운영자가 운영하는 웹사이트와 연동하는 내용을 추가해 2026년 10월 28일부터 시행합니다. 그 전에 앱에서 웹사이트 연동에 동의한 이용자에게는 동의한 때부터 적용합니다. 2026년 10월 27일 개정 내용도 예정대로 시행합니다. 바뀐 내용은 11. 변경 고지에 적었습니다.

## 1. 처리하는 개인정보 항목

| 구분 | 항목 |
|---|---|
| 이메일로 가입·로그인 | 이메일 주소, 비밀번호(복원할 수 없는 방식으로 암호화해 저장) |
| 카카오·Google로 가입·로그인 | 카카오·Google의 회원 식별값, 이메일 주소(제공에 동의한 경우) |
| 서비스 이용 중 이용자가 직접 입력 | 통장 잔액과 기준 시각, 수입일·예정 수입액, 고정지출(이름·금액·날짜), 카드 미결제액, 매달 저축할 돈(이름·금액), 모아둔 돈, 시드머니 반영 기록(주기·방법·금액), 수입·지출 기록(금액·카테고리·내용·메모·일시), 직접 만든 카테고리 |
| 서비스 이용 과정에서 자동 생성 | 가입·약관 동의 일시, 가입 방법(이메일·카카오·Google), 기록의 생성·수정 일시 |
| 앱 업데이트 확인 시 자동 전송 | 앱 설치 식별자(앱 설치 시 무작위로 만들어지며 기기 정보와 무관), 운영체제 종류, 앱 버전 정보, 업데이트 적용 실패 시 오류 내용 |

서비스는 은행·카드사 계좌를 연결하지 않으며, 계좌번호·카드번호·주민등록번호·이름·전화번호·위치 정보를 수집하지 않습니다. 광고 식별자와 이용 행태 분석 도구를 사용하지 않습니다.

카카오·Google로 로그인하면 해당 서비스로부터 회원 식별값과 이메일 주소(제공에 동의한 경우)만 받아 회원 식별과 로그인에 사용합니다. 이름·프로필 사진 등 그 밖의 정보는 저장하지 않으며, 받은 정보는 회원 탈퇴(계정 삭제) 시 즉시 파기합니다.

## 2. 처리 목적

1. 회원 식별, 로그인(카카오·Google 로그인 포함), 계정 관리
2. 입력한 정보를 바탕으로 "오늘 쓸 수 있는 돈" 계산, 거래 내역·소비 분석 제공
3. 문의 응대와 서비스 오류 확인
4. 앱 업데이트 제공과 업데이트 오류 확인
5. 이용자가 요청한 경우 같은 운영자의 웹사이트에서 시드머니 표시와 투자·적금 실험 제공(4. 제3자 제공과 웹사이트 연동)

위 목적 외의 용도로 이용하지 않으며, 목적이 바뀌면 미리 동의를 받습니다.

## 3. 보유 및 이용 기간

- 회원 탈퇴(계정 삭제) 시 **즉시** 모든 개인정보와 기록을 파기합니다.
- 웹사이트 연동으로 웹사이트에 제공한 정보는 연동 해제, 앱 회원 탈퇴, 웹사이트 회원 탈퇴 중 하나가 일어나면 웹사이트에서 즉시 삭제합니다.
- 법령에 따라 보관해야 하는 정보는 없습니다(유료 결제·거래 기능이 없음).
- 서버 장애 대응을 위한 백업에 남은 정보는 백업 보관 주기(최대 7일) 이후 자동으로 삭제됩니다.

## 4. 제3자 제공과 웹사이트 연동

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 특별한 규정이 있는 경우는 예외로 합니다.

**웹사이트 연동**

같은 운영자가 운영하는 텅장관리 웹사이트와의 연동은 제3자 제공이 아니라 이용자가 요청한 연동입니다. 이용자가 앱 [마이 → 웹사이트 연동]에서 아래 내용을 확인하고 동의한 뒤 받은 코드를 웹사이트에 직접 입력한 경우에만 연동됩니다.

- 받는 곳: 같은 운영자(텅장관리)의 웹사이트(solpa.shinhanacademy.co.kr)
- 제공 항목: 앱 이메일·로그인 방법, 시드머니 합계·모아둔 돈·매달 저축할 돈·시작일·마지막 갱신 시각, 주기별 반영 기록(주기 종료일·선택 방법·금액·반영 후 합계·반영 시각). 반영 대기 정보와 거래 내역은 제공하지 않습니다.
- 목적: 웹사이트에서 시드머니 표시와 투자·적금 실험
- 보유 기간: 연동 해제, 앱 회원 탈퇴, 웹사이트 회원 탈퇴 중 하나가 일어나면 웹사이트에서 즉시 삭제
- 해제 방법: 앱 [마이 → 웹사이트 연동]에서 연동 해제, 또는 웹사이트의 내 정보 화면
- 연동하지 않아도 앱의 모든 기능을 그대로 쓸 수 있습니다.

## 5. 처리 위탁

| 수탁자 | 위탁 업무 | 위치 |
|---|---|---|
| Amazon Web Services, Inc. | 서버 운영 및 데이터 저장(EC2, RDS) | 대한민국(서울 리전) |
| Vercel Inc. | 웹페이지(개인정보처리방침·계정 삭제 페이지 등) 제공 | 미국 등. 회원 정보는 저장하지 않음 |
| 650 Industries, Inc.(Expo) | 앱 업데이트 배포(EAS Update) | 미국 |

**국외 이전**

앱 업데이트 제공을 위해 다음과 같이 개인정보를 국외로 이전합니다. 회원 정보(이메일)와 이용자가 입력한 기록은 이전하지 않습니다.

- 이전받는 자: 650 Industries, Inc.(Expo), 미국
- 이전 항목: 1항의 "앱 업데이트 확인 시 자동 전송" 항목과 통신 과정의 IP 주소
- 이전 일시와 방법: 앱 실행 중 업데이트를 확인할 때마다 암호화된 네트워크(HTTPS)로 전송
- 이용 목적과 보유 기간: 앱 업데이트 제공과 오류 확인. 위탁 계약 종료 또는 목적 달성 시까지
- 거부 방법: 업데이트 확인은 앱 실행에 필요해 끌 수 없습니다. 원하지 않으면 앱을 삭제해 주세요. 앱을 삭제하면 기기의 설치 식별자도 함께 지워집니다.

## 6. 파기 절차 및 방법

계정 삭제 요청 시 데이터베이스에서 해당 회원의 정보를 즉시 삭제하며, 복구할 수 없는 방법으로 파기합니다.

## 7. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보를 조회·수정·삭제하거나 처리 정지를 요구할 수 있습니다.

- 조회·수정: 앱의 마이 화면에서 직접
- 삭제(탈퇴): 앱 [마이 → 계정 삭제], 또는 웹 https://project2-flex-sh.vercel.app/delete-account
- 그 밖의 요청: 아래 문의처 이메일. 본인 확인 후 지체 없이 처리합니다.

## 8. 만 14세 미만 아동

서비스는 만 14세 미만 아동의 회원가입을 받지 않습니다.

## 9. 안전성 확보 조치

- 비밀번호 단방향 암호화(BCrypt) 저장
- 모든 통신 구간 암호화(HTTPS/TLS), 데이터베이스는 외부 인터넷에서 직접 접근 불가
- 접근 권한을 운영자로 제한하고, 서비스용 데이터베이스 계정은 최소 권한으로 운영
- 로그인 연속 실패 시 일시 제한

- 시행일: 2026년 10월 28일(그 전에 웹사이트 연동에 동의한 이용자에게는 동의한 때부터)
- 이전 방침 시행일: 2026년 10월 27일, 2026년 10월 14일
