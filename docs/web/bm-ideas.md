# BM 확장 아이디어 — 발표용

대표 답변(2026-10-18): **당장 실제 결제는 하지 않는다.** BM은 발표에서 수익성·시장성을 보여 주는 용도이고 심사 배점이 크다. 서비스가 안정되면 몇 개월 뒤 유료 기능을 검토한다.
기획 담당은 이 문서를 출발점으로 발표 BM 장표를 만든다. 기존 BM(구독·교육 라이선스·캠페인)은 [README §4](README.md#4-bm매출시장), 지키는 선은 decisions 확정 5~7.

## 발표 서사 한 줄

“직접 기록하며 아끼는 습관 → 시드머니 → 웹에서 첫 투자 연습. **청년의 첫 돈 관리를 돕고, 기업·기관은 교육과 참여 기회에 돈을 낸다.**”
습관·기록은 현재 서비스, 투자 연습·교실·리워드는 웹 기획과 발표용 제안이다. 구매 의사·저축 지속 효과는 검증할 가설이다. 개인 구독·기업 교육·공공 사업·광고 캠페인으로 구매자를 나눈다.

## 발표에 넣을 3개

**1·2·3을 선택한다.** 1은 HR·복지 담당, 2는 사업 운영기관, 3은 광고주로 구매자와 예산 용도가 분명하다.
기존 교실·캠페인 기획을 재사용하고, 가입 건별 대가·개인 데이터 제공 없이 제안할 수 있어 6의 금융 제휴보다 규제 부담을 줄일 수 있다.
4는 결제 의사, 5는 집계 기반·용역 수요, 6은 공식 계약이 더 필요해 후순위로 둔다. 도입·수주 확정을 뜻하지 않는다(01 §5-4).

## 발표 BM 장표 초안

### 1장. 첫 월급을 기록하는 습관에서 시작한다

**핵심 메시지:** 청년의 돈 관리 습관을 무료로 돕고 교육 구매자로 확장한다.

- 현재 서비스: 사용자가 직접 입력한 잔액·기록 기준 추정으로 오늘 쓸 돈을 보여 준다.
- 시드머니를 기록하고, 웹에서 가상 금액으로 첫 투자 연습을 돕는 흐름을 제안한다.
- 기업은 신입 교육, 기관은 자산형성 교육, 스폰서는 광고 캠페인의 구매 후보다.
- 웹 교실·기관 패키지·리워드는 기획 단계다. 구매 의사·저축 지속 효과는 검증 전이다.

근거: 이 문서 §발표에 넣을 3개, 01 §5-4·§6.

### 2장. 개인 구독 위에 기업·기관 매출을 더한다

**핵심 메시지:** 교육·복지·광고의 서로 다른 예산을 구매 경로로 제안한다.

- 개인: 월 990원·연 9,900원 플러스 구독. 당장 실결제는 하지 않는다.
- 1 기업: HR·복지 담당이 플러스·교육 묶음 이용권을 좌석 단위로 구매.
- 2 공공: 자산형성 사업 운영기관이 기록 습관·금융교육 보조 좌석을 구매.
- 3 스폰서: 상품 가입 조건 없이 목표 기록 캠페인을 후원. 고정 광고비와 리워드 재원 분리.
- 기존 교실·캠페인과 같은 계약은 한 번만 계상한다.

근거: README §4, 01 §5-4·§5-7, 이 문서 §자산형성 사업 확인.

### 3장. 기본 시나리오 연 61,960,000원, 모두 가정

**핵심 메시지:** 확인한 모집단에 미검증 단가·도입률을 적용한 발표용 매출이다.

- 기존 기본 연 매출 29,720,000원 + 확장 32,240,000원 = 61,960,000원(가정).
- 1: 10곳 × 50석 × 20,000원 = 10,000,000원. 2: 724명 × 10,000원 = 7,240,000원(가정).
- 3: 추가 1건 × 15,000,000원 = 15,000,000원(가정, 리워드 재원 제외).
- 기존 포함 연 합계는 보수 7,220,000원 / 기본 61,960,000원 / 낙관 285,140,000원(가정).
- 공식 모집단은 공시 대상 342곳·2026년 사업 최종 선정 24,145명. 도입·계약 실적이나 이익은 아님.

근거: README §4 확장 BM 표·합산 조건, 이 문서 §단가·시장 규모 추정의 공식 출처.

### 4장. 이용 지표는 테스트 결과로 채운다

**핵심 메시지:** 실제 사용과 재방문을 확인한 뒤 구매자에게 제안한다.

- 가입 수: [11/4 테스트 후 채움]. 집계 기간·중복 제외 기준을 함께 적는다.
- 7일 재방문: [11/4 테스트 후 채움]. 관찰 7일이 지난 가입 집단의 분모·재방문 정의를 적는다.
- 첫 실험 완료율: [11/4 테스트 후 채움]. 대상·완료 기준·분모를 함께 적는다.
- W3 11/2~11/4만으로 7일 재방문을 계산하지 않는다. 관찰 미완료 집단은 미관측으로 적고 뒤에 갱신한다.

근거: 이 문서 §발표에서 숫자로 보여 줄 것. 아직 측정값 없음.

### 5장. 팔 것은 교육·광고, 지킬 것은 기록의 신뢰

**핵심 메시지:** 개인 기록과 금융 판단을 수익 거래의 대상으로 삼지 않는다.

- 가입 건별 중개 수수료·종목 판단·추천·개인 데이터 판매 없음.
- 상품 가입을 리워드 조건으로 걸지 않고, 캠페인은 광고로 표시한다.
- 기업·기관은 개인 기록을 볼 수 없고 참여 통계만 받는다.
- 결제는 웹에서만. 앱 안 가격·결제 링크 없음. 당장 실결제 없음.
- 계약 전 금융사 브랜드 미사용. 계좌 연결·소비 패턴 분석 등 없는 기능을 구현된 것으로 쓰지 않는다.

근거: README §4, 01 §5-4·§5-7, 이 문서 §추가 아이디어의 제한.

사람이 확인할 남은 일:

1. HR·사업 운영기관·스폰서의 구매 관심 확인. 교육기관 1곳 관심 확인과 발표 목업 준비(01 §5-4). 외부 도구 교육 인정·위탁·조달 방식·구매 예산 확인.

3. 가입 수·7일 재방문·첫 실험 완료율을 [11/4 테스트 후 채움]에 입력. 관찰 기간·분모를 확인하고, 캠페인 리워드의 자기 기록 확인 방식과 저축 지속 효과를 검증.
