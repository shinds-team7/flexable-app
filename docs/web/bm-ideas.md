# BM 확장 아이디어 — 발표용

대표 답변(2026-10-18): **당장 실제 결제는 하지 않는다.** BM은 발표에서 수익성·시장성을 보여 주는 용도이고 심사 배점이 크다. 서비스가 안정되면 몇 개월 뒤 유료 기능을 검토한다.
기획 담당은 이 문서를 출발점으로 발표 BM 장표를 만든다. 기존 BM(구독·교육 라이선스·캠페인)은 [README §4](README.md#4-bm매출시장), 지키는 선은 decisions 확정 5~7.

## 발표 서사 한 줄

"무료로 매일 아끼는 습관 → 시드머니 → 첫 투자 연습. **청년이 처음 금융 고객이 되는 순간의 입구**를 우리가 갖는다."
금융사가 가장 비싸게 사는 고객은 첫 거래를 시작하는 청년이다. 우리는 그 직전 단계(습관·시드머니·이해)를 무료로 만들어 주고, 돈은 세 갈래(개인·기업·공공)에서 받는다. 한 곳에 기대지 않는다.

## 발표에서 숫자로 보여 줄 것

- **실측 지표**: Play 비공개 테스트와 W3 사용자 테스트(11/2~11/4)의 실제 수치(가입 수, 7일 재방문, 첫 실험 완료율). 예상치와 섞지 않는다.
- **매출 구성 그림**: 개인 구독(작지만 지불 의사 검증) + 기업·금융사(1·3·6) + 공공·교육(2·교실 라이선스). README §4 시나리오 표에 1·2·3을 같은 가정 형식으로 추가한다.
- **가격 문구**: 월 990원 = "커피 한 잔보다 싼 값", 연 9,900원 기본.

## 기획 담당에게 넘길 일

1. 아이디어 1~6 중 발표에 넣을 3개 고르기(추천: 1·2·3. 구매자가 분명하고 규제 부담이 작다).
2. 고른 항목의 단가·시장 규모를 출처와 함께 추정하고 README §4 시나리오 표에 반영.
3. 2번(자산형성 사업)의 실제 사업명·교육 요건 출처 확인.
4. 발표 BM 장표 초안(서사 → 매출 구성 → 숫자 → 지키는 선).
