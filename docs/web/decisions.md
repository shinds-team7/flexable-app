# 웹사이트 기획 — 팀장 확정 사항(3라운드 기준)

2라운드 기획·디자인·아키텍처 리뷰(교차 리뷰 기록, 저장소에 없음)를 읽고 쟁점을 아래처럼 확정한다. 3라운드에서는 **자기 문서에 온 리뷰 + 이 확정 사항**을 반영해 문서를 고친다. 이 확정과 다른 리뷰 의견은 따르지 않는다(반대하면 문서 끝 "남은 이견"에 근거와 함께 한 줄).

## 확정 사항
1. **시드머니**: 확정값 = 끝난 정산 주기마다 (수입 − 지출, 고정지출 포함)의 누적. 보조 숫자 2개를 둔다 — `current`(이번 주기 남기는 중, 확정 전, 거래 입력 즉시 바뀜)와 `todaySaved`(오늘 아낀 돈, 표시 전용·누적 금지). 사용자가 시드머니를 **직접 수정**할 수 있다(수정값 우선, "직접 입력" 표시). 시연 대본의 "거래 1건 → 웹 숫자 변화"는 `current`로 보여 준다.
2. **시뮬레이션 기본값**: 넣는 방식 3종(한 번에 / 매달 나눠서 / 지금 저축 속도로) 중 기본은 **"지금 저축 속도로 + 3년 전부터"**. 기간 칩(1·3·5년)과 날짜 직접 지정 모두 **무료**.
3. **매수 단위**: 소수점 매수로 계산하고 "소수점 매수를 가정한 결과(실제 증권사마다 다름)"를 결과 아래 고지. 원 단위 정수·내림은 금액에만 적용.
4. **범위**: 국내 주식 + 국내 상장 지수 ETF(미국 지수 추종 포함). "해외(이후)"처럼 아직 없는 기능은 화면에 노출하지 않는다.
5. **사건 설명은 전부 무료**(핀 툴팁·상세 패널·근거 링크 모두). 종목 판단·전망·AI 종목 상담은 유료·무료 모두 없음. 사건 상세 응답은 기획 템플릿(무슨 일 / 시장 반응 / 그 뒤에는 / 근거 / 고지) 그대로 API 필드로.
6. **적금**: "순위" 열·"가장 많은 건 ○○" 같은 추천형 문장 금지. 사용자가 고른 정렬(기본금리·최고금리·기간)만. "내 조건 금리"는 데이터가 없어 제외. 과거 시점 비교는 한국은행 평균 금리 한 줄(상품별 과거 금리 없음). **정책 적금(청년미래적금) 계산 화면 추가**(조건 직접 입력). 가입 버튼 없음.
7. **무료/유료(월 990원 / 연 9,900원, 연 기본 선택)**
   - 무료: 소식 전부(맞춤 필터 포함), 타임머신(적립식·거치식, 기간 칩·날짜 지정, 종목 3개, 사건 설명 전부), 적금 비교·정책 적금, 조합(프리셋 3개·비교 2개), 공유 링크, 목표 1개
   - 유료: **정책 마감 리마인더**(대표 가치), **월간 '내 돈 리포트'**(내 기록 해설만), 정밀 모드(배당 재투자·수수료·세금), 저장 확대(프리셋 50·비교 5·종목 5), 광고 없음
   - 한도 숫자는 설정값으로. 잠금은 첫 결과를 막지 않고 그 자리 팝오버(페이지 모달 금지)
8. **해커톤 범위에서 뺌/축소**: 우대조건 반영, 계정 합치기, 이메일 실제 발송(화면 시연만), 서버 저장 개인화 고도화, 실시간 AI 생성(사전 생성 샘플만), 앱 홈 목표 표시(웹 목표 설정만 Should).
9. **추가**: 목표 설정(웹), 공유 페이지, 결제 결과 화면(모의), 온보딩 '봤음' 저장, 자체 사용 지표 이벤트 로깅 API(대중성 실측용, 개인 식별 최소).
10. **로그인 문구**(앱에 이미 반영): "카카오 로그인" / "Google 계정으로 로그인" / "이메일로 로그인". 카카오 가이드대로 #FEE500·심볼 #000·레이블 #000 85%·radius 12. 웹도 같은 세 버튼(이메일은 연한 버튼, 글자 링크 아님).
11. **시연 페르소나 통일**: '지수'(사회초년생, 시드머니 47만원, 월 저축 속도 7.8만원). 세 문서의 예시 숫자를 이것으로.
12. **오프라인 시연**: 시연 데이터 스냅숏 + 사전 생성 설명이 기본 경로. 폐쇄망이면 소셜 로그인 대신 시연 계정(이메일).
13. **플러스(요금표·모의 결제)는 해커톤 Must.** 심사에서 BM을 화면으로 보여 준다. 월간 리포트는 샘플 화면 1장(Should), 정밀 모드는 해커톤에서 뺀다.
14. **새 웹의 OAuth 콜백 경로는 `/oauth/callback`.** 앱·Expo 웹과 같은 흐름(`start → callback → exchange`)을 쓰고, 서버 `OAUTH_ALLOWED_REDIRECT_URIS`에 새 웹 주소만 추가한다.
15. **시드머니 직접 수정 API는 `PUT·DELETE /api/v1/me/seed-money/manual`.**
16. **사용 지표 원시 이벤트는 30일 보존 후 삭제, 집계만 유지.** 수집 시작 전에 개인정보처리방침에 반영한다.
